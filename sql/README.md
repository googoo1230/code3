# SQL 데이터베이스 파일

이 폴더는 SQL 관련 자료를 위한 위치입니다.

`hospital_db.sql`은 팀원이 제공한 MySQL 덤프이며 4개 테이블(`hospital`, `region`, `department`, `hospital_dept`)과 데이터가 포함되어 있습니다. 덤프 파일은 용량이 커서 GitHub에 올리지 않고 팀 공유 저장소에서 별도로 전달합니다.

덤프를 복원하는 방법과 Python 조회 프로그램 실행 방법은 프로젝트 루트의 `README.md`를 확인하세요.

**보안:** 각자 MySQL 비밀번호를 `app/config.py`에만 입력하고 이 파일은 GitHub에 업로드하지 않습니다.
